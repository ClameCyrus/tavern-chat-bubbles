## 聊天气泡配置

通用版的「外观配置面板」新增「保护外观」和「线上聊天输出规则」。保护外观默认开启，防止酒馆主题或状态栏 CSS 覆盖气泡的间距、圆角、描边和阴影；关闭后允许主题改变外观。关闭动画时气泡仍会显示。

输出规则只编辑使用场景、填写说明、类型说明和示例，固定字段结构保持不变。保存后会同步到「【聊天气泡】线上聊天输出格式」世界书条目；自定义规则按格式条目所属世界书独立保存在脚本变量中，重刷、切换聊天及更新 CDN 脚本时继续使用。

「恢复默认输出格式」只恢复输出规则并更新格式条目；「重置外观配置」保留已保存的输出规则。面板导出的 JSON 同时包含外观与输出规则，导入旧的纯外观 JSON 或配置文本时保留当前输出规则。

芙林专属版同步了显示兼容和外观保护；可通过外观配置条目的 `protect_appearance = false` 关闭保护，其原有输出格式和按钮保持不变。
