# 聊天气泡兼容与输出规则检查

- 通用版新增外观保护开关，默认开启；关闭后恢复主题对圆角、边框、阴影和边距的影响。两种模式下，关闭入场动画都不会让气泡永久透明。
- 通用版输出规则与外观独立存储；格式条目仅由固定结构和保存的规则合成。未修改条目解析器。
- 格式恢复默认只更新格式条目；执行真实外观重置按钮回调及其后续注入流程，已保存的自定义规则保持不变。
- 导入旧外观文件保留现有规则；新导出文件包含外观和输出规则。
- 浏览器隔离检查：通用版与芙林版分别在保护开关两种模式下测试主题的全局边框、阴影、圆角、动画重置和状态栏的间距重置；保护开启时气泡 padding 为 10px 14px、线程内消息 margin 为 12px 2px、状态 padding 为 0px 4px、卡片居中且描边可见。保护关闭时允许这些样式被覆盖，但气泡仍可见。
- 图片回退文字的 display:none、伪元素光环和 150ms 消息入场延迟均保留。
- 浏览器隔离面板检查：规则编辑保存、格式单独恢复、未保存的外观修改状态和旧文件导入通过；1000px、390px、320px 下无横向溢出。
- TypeScript 检查、Vue 编译、两个入口的语法检查及 git diff --check 通过。面板及新增模块 ESLint 通过；两个原有 JavaScript 入口仍有基线中的 50 和 52 个错误，本次未新增。
- 没有开启实时监听、运行项目构建、刷新酒馆或写入用户实际世界书。浏览器验证在临时隔离 iframe 中完成，结束后已移除。
